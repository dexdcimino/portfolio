# Onboarding a new AI session

Paste one of these. That's the whole job.

**Any session with a shell:**

```
Clone my portfolio repo — github.com/dexdcimino/portfolio — and read
ARCHITECTURE.md. Then:

[what I want to build]
```

**Claude Code, already inside the repo:**

```
Read ARCHITECTURE.md, then:

[what I want to build]
```

- It reads the last **pushed** commit — push first if mid-change, and another
  session's uncommitted work is invisible to it.
- Per-area docs sit beside the root one: `games/surveyor/ARCHITECTURE.md` and
  the three other games.
- Structural changes update the relevant `ARCHITECTURE.md` in the same commit.
