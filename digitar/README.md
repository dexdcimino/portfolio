# DIGITAR — the digital Dex project

**What this is.** A permanent, growing, text-first record of who Dex Cimino is — his history, voice, vocabulary, mannerisms, beliefs, decision patterns, and hard factual boundaries — kept at an S-tier standard so that any AI working with him can represent him accurately: emails, applications, messages, site copy, descriptions, promotions, and (later phases) voice and avatar performance.

**Why it exists.** On 2026-10-15 an outreach draft falsely claimed Dex "makes short AI video pieces for a living" (truth: ~7 AI clips ever, <80 seconds total, $0 earned). Fluent-but-false is the failure this project exists to prevent. It is also the seed of something bigger: a repeatable system anyone could follow to digitize themselves.

**FRONT-LINE RULE FOR ANY AI READING THIS:** before writing anything AS Dex — an email, an application, a message, a description — read `profile/claims-ledger.md` and `profile/voice-profile.md` first. If a draft conflicts with the ledger, the ledger wins. If you don't know something, leave it out; never invent a plausible fact about this person.

**Structure.**
- `raw/` — verbatim captures (voice dumps, key threads, his own edits). Append-only, dated, never polished.
- `profile/` — distilled living documents (voice profile, claims ledger, beliefs, history). Traceable to raw sources.
- `methods/` — the instruments that grow this archive (questionnaires, capture protocols) and their returns.

**Discipline.**
- Text only, kept lean and intelligent — no bulk, no pointless data; record what might matter later, skip what can't.
- Every fact carries a date and, where it matters, a source. Beliefs and facts that change get SUPERSEDED, never silently overwritten.
- Register is data: Dex has modes (raw / working / polished). The archive records which mode a capture came from.
- This folder lives in the portfolio repo for backup + AI access, and is excluded from the public website deploy via `.vercelignore`. The equally-current working copy lives in Bash's workspace (`~/workspace/dex-archive/`); both are updated together after every significant capture.

**Phases (see ROADMAP.md).** 1) Text brain (now). 2) Voice mapping. 3) Avatar performance (his own 3D models, head/face tracking, his voice). 4) A kit others can follow.

Started 2026-10-15 by Dex + Bash.
