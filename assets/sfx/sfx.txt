# THE SOUND LIBRARY, hand-written. One line per TRACK.
#
#     Category | Item | Variant | File
#
# A CATEGORY is a section in the overlay and a row in its sidebar. An ITEM is
# one card in that section -- "Bow, draw" -- and every line sharing a category
# and an item is one option in that card's dropdown. The number beside the
# dropdown is how many of those there are; nothing counts them by hand.
#
# THE FILE is a path under assets/sfx/, or "-" for a sound that is wanted and
# not sourced yet. A dash is not a failure: this file is the WISHLIST as much
# as the manifest, and a card with nothing behind it says so on its face
# rather than being left out and forgotten. `python tools/bake_sfx.py` prints
# how many of each there are on every run.
#
# ORDER MATTERS and is the order here: categories appear in the order they are
# first mentioned, items in the order they are first mentioned inside one.
#
# Blank lines and lines starting with # are ignored. After editing, run
#
#     python tools/bake_sfx.py
#
# which rewrites assets/sfx/sfx.json. Never edit that file; --check fails on a
# hand edit because the output is a byte comparison against a rebuild.
