# Style Pass

> PLACEHOLDER — replace with the real prompt.

Edit the text below for rhythm and clarity. Keep the voice. If a stranger could
not tell the edit from the original, you have gone too far the other way — but if
it no longer sounds like me, you have failed outright.

## Keep

- Contractions, sentence fragments, and the odd long sentence that earns it.
- Specific nouns. "The 2 a.m. build" beats "a late build".
- Jokes that are actually funny in context.

## Cut

- Throat-clearing: "It's worth noting that", "At the end of the day".
- Adverbs propping up a weak verb.
- Any sentence that restates the one before it.
- Hedging stacked two deep: "might possibly", "seems to suggest".

## Never

- Add facts, numbers, names or claims that are not in the source.
- Turn a plain sentence into a slogan.
- Use em dashes to smuggle in a second sentence — split it instead.

## Output

The edited text first, on its own, ready to paste. Then a short list of the
changes you would defend if I pushed back, one line each.
